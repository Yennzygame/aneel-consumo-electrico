1. El problema de escala¶

Tres segmentos pueden tener la misma forma (suben en verano, caen en invierno) pero escalas muy distintas. Si se clusteriza la serie en MWh crudos, el algoritmo separa por tamaño, no por comportamiento. La solución es normalizar por fila (cada serie contra su propia media y desviación), de modo que todas las unidades pesen igual y el clustering describa forma.

2. Descriptores de forma¶

Cada serie se resume en 19 descriptores interpretables. No incluyen el nivel de consumo (total_mwh se guarda aparte, solo para interpretar y para exponer riesgo por distribuidora). Así el clustering no puede separar “grande” de “pequeño”: solo “cómo se mueve”.

Interpretación de los descriptores clave

  • tendencia_pct_mes: pendiente OLS como % de la media mensual. Es comparable entre segmentos de distinto tamaño.
  • crecimiento_12m: promedio de los últimos 12 meses / promedio de los primeros 12 − 1. Mide el cambio de régimen, no el ruido mensual.
  • drawdown_max: mayor caída desde un máximo previo. Distingue una caída sostenida de una serie que solo oscila.
  • cv, amplitud_estacional, fuerza_estacionalidad: volatilidad y estacionalidad.
  • ac1, ac12: persistencia mensual y anual.
  • pico_sin/cos, valle_sin/cos: codificación circular del mes de máximo/mínimo (evita que diciembre y enero queden “lejos”).

from src.aneel_pipeline import row_minmax, row_zscore

def winsor_fila(df, q=0.01):
    return df.clip(lower=df.quantile(q, axis=1), upper=df.quantile(1 - q, axis=1), axis=0)

def aplicar_escalado(df, nombre):
    if nombre == "z_fila":
        return row_zscore(df)
    if nombre == "minmax_fila":
        return row_minmax(df)
    if nombre == "winsor_z_fila":
        return row_zscore(winsor_fila(df))
    raise ValueError(nombre)

comparacion = pd.DataFrame({
    "crudo_media": serie.mean(axis=1),
    "crudo_std": serie.std(axis=1),
    "z_fila_media": aplicar_escalado(serie, "z_fila").mean(axis=1),
    "z_fila_std": aplicar_escalado(serie, "z_fila").std(axis=1),
    "minmax_fila_min": aplicar_escalado(serie, "minmax_fila").min(axis=1),

5. Conclusión¶

  • La unidad de análisis es el segmento distribuidora × clase (700 unidades).
  • La serie de 68 meses es la representación más rica, pero exige normalizar por fila para que el tamaño no domine.
  • Los descriptores ofrecen interpretabilidad y robustez; el PCA ofrece compacidad. Las tres compiten en igualdad de condiciones en el DoE.
  • El nivel de consumo (total_mwh) se mantiene fuera del clustering y se usa después para ponderar el impacto económico de cada arquetipo.
